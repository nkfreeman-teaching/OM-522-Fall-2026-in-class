FlowSim model builder

Draw a service network, set its durations and behaviors, and copy the FlowSim script it writes. The script is ordinary FlowSim code to edit further, and running it is the final check of the model.

Not in this builder: supply chains. Add them by editing the script. The builder never chooses a behavior for you: when a feature needs a rule (what an off-duty server does, what happens when a buffer is full, when patience or a failure clock runs), Checks lists it until you choose.

Customer types

    Without types, every customer is alike. With types, each source sets its type mix, and each arrow can carry every type or only some. A node's second arrow asks, in the side panel, whether its customers split by probability or by customer type.

    Drag a node to move it. Drag from the dot on a node's right edge to another node to add a route. Two or more routes from one node make a branch, with a probability on each arrow. Select a node or an arrow to edit it, and press Delete to remove it. From the keyboard, Tab reaches each node and arrow, Enter edits it in the side panel (where Add route connects nodes), the arrow keys move a node (Shift moves farther), Delete removes it, and Escape clears the selection. Ctrl+Z undoes and Ctrl+Shift+Z or Ctrl+Y redoes outside a text field. Arrange places the nodes left to right along their routes.
