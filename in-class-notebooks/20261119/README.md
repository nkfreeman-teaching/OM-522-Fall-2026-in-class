# OM 522, November 19: push against a limit on work in the shop

This folder has its own environment and a copy of the FlowSim library (version 2.0.2), so it runs
with nothing else installed.

| Notebook | Open it with | What it is |
|---|---|---|
| `push_and_limits.py` | `pixi run class` | A three-station shop run with no limit on releases and with racks of 2 and 1, over 100 matched shifts |

Run `pixi install` once, from this folder, before the first command.

```bash
cd in-class-notebooks/20261119
pixi install
pixi run class
```
