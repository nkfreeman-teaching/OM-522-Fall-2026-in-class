# OM 522, December 1: where to spend the next dollar

This folder has its own Pixi environment, a copy of the FlowSim library (version 2.0.2), and a copy
of the November 3 shop data in `data/`, so with Pixi installed it needs nothing else.

| Notebook | Open it with | What it is |
|---|---|---|
| `next_dollar.py` | `pixi run class` | The November 3 Cut, Weld, and Paint line, today's version of it against four ways to spend one budget, on the same 100 shifts |

Run these commands from the root of the in-class repository. `pixi install` is needed only the first time.

```bash
cd in-class-notebooks/20261201
pixi install
pixi run class
```
