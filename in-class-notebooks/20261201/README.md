# OM 522, December 1: where to spend the next dollar

This folder has its own environment, a copy of the FlowSim library (version 2.0.2), and a copy of
the November 3 shop data in `data/`, so it runs with nothing else installed.

| Notebook | Open it with | What it is |
|---|---|---|
| `next_dollar.py` | `pixi run class` | The November 3 Cut, Weld, and Paint line, and five ways to spend one budget on it, over 100 matched shifts |

Run `pixi install` once, from this folder, before the first command.

```bash
cd in-class-notebooks/20261201
pixi install
pixi run class
```
